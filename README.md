I'm an **Intermediate Developer** at **Henry Schein One**, on [Dentally](https://www.dentally.com/en-nz/). I spend most of my time in Rails and Ember, and I also like building with .NET and React. I lead large complex projects, improve developer experience, and mentor junior developers.

I'm a Computer Science graduate (Bachelor of Science) from Massey University. On GitHub since **July 2020**.

Off the clock I'm a triathlete and a helicopter pilot. If you want to talk about a role, a bug, or a ride, email is the most reliable way to reach me: [greenwood.maysen@gmail.com](mailto:greenwood.maysen@gmail.com).

### A few things I've shipped

- **[ZWO Builder](https://zwo-builder.pages.dev)** — a Zwift workout editor. Drag blocks around, describe a change in plain English, export a `.zwo`. I built it because clicking intervals together in-game is slow. [Code](https://github.com/MaysenTG/zwift-workout-creator)
- **[Who Funds NZ](https://whofunds.nz)** — an unofficial explorer of large donations to New Zealand political parties, drawn from returns the Electoral Commission publishes. [Code](https://github.com/MaysenTG/nz-party-donations-explorer)
- **[Static site creator](https://static-site-creator.fly.dev)** — edit a site in the browser and publish it. The assets live on Cloudflare R2. [Code](https://github.com/MaysenTG/ror-gcs-site-creator)
- **[Planedle](https://maysentg.github.io/planedle/)** — a daily guess-the-aircraft game. You get a zoomed-in photo, and each wrong guess zooms out. [Code](https://github.com/MaysenTG/planedle)

More on [maysengreenwood.com](https://maysengreenwood.com).
